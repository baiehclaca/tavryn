About Language Roadmap GitHub

Code with declared authority.

Tavryn is a programming language project for software that acts on someone's behalf. A program declares what it needs to do. The host decides what it may do.

The idea

Software can read private information, change files, send messages, and spend money. Tavryn aims to make those actions visible in code and limited by the person or system running it.

The current interpreter shows the first part of that idea with local files: a program asks for access, the host grants access separately, and both are required before a file action runs.

The language today

This Tavryn program reads a message and saves a draft. It does not send anything.

needs read "inbox/*.txt"
needs write "drafts/*.txt"

let message = read("inbox/message.txt")
let reply = "Draft reply: " + message
write("drafts/reply.txt", reply)
say("Saved the draft.")

Declaring a permission in the program does not grant it. The host must also allow it. Run the interpreter locally.

The long-term plan

Tavryn is being developed as a years-long language project. The next work is to specify functions, types, and effects; build a safer runtime and useful tools; connect to existing systems; and test the language in real applications before a stable 1.0 release.

Read the full roadmap and architecture.

Current status

The interpreter is experimental. It supports a small language and local file permissions. It does not yet have general-purpose functions, a type system, networking, packages, or a production security audit.

The name and licensing terms are still provisional. See the security status and source code.
