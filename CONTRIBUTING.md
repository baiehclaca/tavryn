# Contributing

The project is being organized for long-term development. The source is public for review and experimentation, but no open-source license or contributor agreement has been chosen. Please open issues for bug reports, use cases, and design criticism. **Do not submit code pull requests yet**; contribution and intellectual-property terms must be settled first.

For reproducible bug reports, include the `.tav` program, the command used, your Python version and operating system, the expected result, and the actual result. Remove secrets and private file contents first.

The next useful discussion is the target language contract: how functions expose effects, how hosts grant bounded capabilities, and how the runtime proves that adapters cannot exceed them.
